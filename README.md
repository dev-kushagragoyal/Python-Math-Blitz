# Mental Math Quiz Game
A simple terminal-based Python game that tests your skills in calculating the squares and cubes of numbers. 

# Features
- Two Game Modes: Choose between calculating Squares or Cubes.
- Four Difficulty Levels:
  - Easy: Numbers from 1 to 10
  - Medium: Numbers from 11 to 20
  - Difficult: Numbers from 21 to 35
  - Extreme Difficult: Numbers from 36 to 50
- Custom Rounds: Choose how many questions you want to play.
- Score Tracking: Displays your total score at the end of each game.

# How to Run
1. Ensure you have Python installed on your system.
2. Download or copy the game code into a file named `main.py`.
3. Open your terminal or command prompt, navigate to the folder, and run:
   python main.py

# Requirements
- Python 3.x
- No external libraries required (uses built-in 'time' and 'random' modules)
